# Microbial Genome Analysis Notes

## Assembly
- Long-read assemblies can be evaluated using assembly size, contiguity, and coverage.
- Flye is useful for de novo assembly of long-read sequencing data.

## Quality Control
- QUAST provides assembly statistics.
- BUSCO evaluates genome completeness.
- CheckM2 can estimate completeness and contamination.

## Taxonomy
- Kraken2 provides rapid taxonomic classification.
- ANI can be used for genome-level species identification.
